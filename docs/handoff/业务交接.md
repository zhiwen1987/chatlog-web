# 客户使用与日常管理交接

客户签收的重点是能安全用和取回数据，不是代码目录数量。

| 事项 | 演示与核实 |
|---|---|
| 登录与角色 | 管理员/员工/分析角色真实权限、MFA、应急恢复、离职撤权 |
| 安装 | 正确OS/架构安装与升级，旧数据保留，失败可解释 |
| 来源同意 | 哪个账号、哪个目录、哪些媒体、谁批准；不默认全盘采集 |
| 查询 | 查一条消息、上下文、跨年关键词，说明覆盖和未解析 |
| 媒体 | 图片/视频/语音/文件的预览、原件与完整性、源缺失含义 |
| 画像 | 证据、推断、冲突、人工纠正、外部AI费用/外发开关 |
| 功能许可 | 平台许可与企业开关不同，到期仍可按权限取回历史 |
| 同步异常 | 在线/离线与停滞分开，暂停/恢复，失败项安全重试 |
| 备份 | 最近成功集合、独立故障域、恢复演练、密钥保管者 |
| 数据取回 | 标准导出、原件下载、限制/冷恢复、清理与备份保留期限 |
| MCP | 哪些Host获授权、scope/数据外发范围、撤销办法 |
| 支持 | 错误码/请求ID/脱敏诊断；不要将整库发到群聊 |

交接记录填实际产品版本、完成日期、演示账号角色（不写密码）、操作结果和客户确认范围。未购买功能与未实现功能分开显示，不能把未实现写成未购买掩盖交付缺失。

初次试传先用合成数据；接真实数据前确认来源权利、保留策略和外发政策。功能说明及安装说明均需与这一发行版本一致，旧截图不得当新功能证据。
