# 验收与签收清单

文档4.3。本清单是签收流程，不替代规则R27～R30/R41/R42/R43的完整测试。**当前所有产品项not_tested，签收人待实际指定。**

## 关口一：文档包可用

核对文件摘要、相对链接、Skills格式、MCP目录来源和所有“示例/未验证”标记；运行本包校验和其单元测试。只能签收“文档已收到且可解析”。

## 关口二：工程可运行

固定commit/合同/migration/依赖版本，真实构建通过；REST/Web/MCP/Worker共用权限；来源、媒体、画像和授权至少完成实际合成闭环。没有安装/容量证据时仍不等于正式版。

## 关口三：产品功能与风险

| 必测组 | 真实证据要求 |
|---|---|
| 数据 | 重传、低位回填、同内容不同消息、断电恢复、清洗回滚、防删除复活 |
| 媒体 | 四类原件、50GiB文件断点、分片/全文件hash、缺失与排除状态、播放副本隔离 |
| 查询 | 中文短词/符号/跨chunk/跨年与oracle一致、索引滞后补差、深分页 |
| 心跳/调度 | 休眠/重连/乱序/重放、observer故障、旧fencing、混合负载保控制面 |
| 权限/MCP | OAuth错误audience、越权对象、工具隐藏后直调、任务/URL越权、prompt注入 |
| 授权 | 单feature期限、依赖/配额、批量冻结/审批/幂等/冲突/恢复、published≠applied |
| 安装 | 每目标OS/架构干净机、签名更新、迁移兼容、卸载保留数据 |
| 容量性能 | C1和C2分别实测，环境/实际bytes/分布/延迟/错误率，不能稀疏文件冒充 |
| 恢复 | PG+对象+key+删除/撤销账本一致，隔离恢复后抽检和全量manifest校验 |
| 交接 | 独立维护者能定位/复现一个问题，按手册重做安装并明确未完成项 |

## 关口四：发布与签字

逐项填写实际结果、证据路径/hash、代码版本、测试环境、复核者。pass/fail/blocked/not_tested/不适用需批准五类分开；blocked不计通过。签字分工程负责人、安全负责人、运维和业务接收人，不让模型代签。

正式发行清单只有在必需证据齐备才标`release_verified`；文档版本号不能代替产品版本。完整状态模板在[IMPLEMENTATION_STATUS](../../templates/IMPLEMENTATION_STATUS.example.json)。

缺项必须说明影响、owner、恢复步骤与审批依赖；不允许用“后续优化”“已基本完成”替代未交付范围。
