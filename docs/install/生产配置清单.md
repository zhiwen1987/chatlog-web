# 生产配置登记清单

这是语义清单，不是程序已支持的环境变量名。实际键名、默认值和校验位置由固定版本配置Schema与发行manifest填写，不凭本文猜`WCM_*`参数。

| 配置域 | 必填内容 | 校验与危险值 |
|---|---|---|
| 标识 | 产品版本、部署ID、node ID、可信发行域 | 不能每次容器重启生成新商业部署 |
| 网络 | 公共HTTPS origin、TLS链、受信代理、CORS/Origin白名单 | 禁止关闭证书验证、任意公网DB端口 |
| 身份 | issuer、audience、redirect URI、scope映射、恢复管理员 | 禁止共享默认密码、混用客户与issuer token |
| PG | 受限账号、连接池总预算、迁移owner、卷、备份stanza | 所有副本连接数合计，不用superuser跑业务 |
| 对象 | 后端类型、bucket/前缀、加密、multipart与校验能力 | 不记录secret；不跨tenant hash存在性探测 |
| 搜索 | 模式、索引版本、分片、水位、严格补差预算 | 不把索引落后当作全库无结果 |
| 调度 | 每tenant与source预算、交互保留槽、CPU/I/O/网络额度 | 重媒体不能抢光心跳/取消/查询 |
| 数据保留 | 原始/修订/附件/暂存/日志/备份各自TTL | 不自动删除未ACK；删除账本不能过早过期 |
| 商业许可 | 可信公钥集引用、租约策略、最低协议、配额口径 | 不放发证私钥；不允许LICENSE_DISABLED生产绕过 |
| AI/外发 | provider、模型、保留政策、目的/范围同意、费用预算 | 开发模型key不打进业务镜像；默认无外发 |
| MCP | endpoint、版本矩阵、Host注册、scope/profile、输出预算 | 默认最小只读；无SQL/Shell工具 |
| 日志/告警 | 脱敏规则、保留、请求关联、报警渠道 | 不记录完整正文/签名token；避免无界label |
| 更新 | 可信manifest位置、签名公钥、通道、回滚兼容范围 | 不用latest不验签；不自动改来源目录 |

所有秘密只登记受限保管系统的引用ID、owner和轮换时间；`.env.example`不含真实值。配置改动需版本、操作者、差异及恢复办法；功能开关不能改变身份和商业授权事实。
