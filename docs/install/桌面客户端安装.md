# 桌面客户端安装、配对与恢复

目标是普通员工不需编译工具即可安装。本文为目标发行SOP，本包未附EXE/MSI/DMG/DEB/AppImage；真实可用平台以发布manifest和干净机测试为准。

## 安装前

确认系统、CPU架构、可用空间、服务器HTTPS地址和授权管理员提供的短期配对信息。关闭已存在的重复采集实例前先查看未完成队列；不要卸载旧版来“清空红色错误”。从可信下载页拿对应文件，校验签名和摘要。

| 平台 | 安装动作 | 必须处理的差异 |
|---|---|---|
| Windows | 运行签名安装器，按向导安装 | x64/ARM64，WebView2在线/离线依赖，用户级/系统级权限、被占用文件；不能默认管理员运行采集 |
| macOS | 打开正式签名公证DMG/应用并按说明安装 | Intel/Apple Silicon，首次网络/文件访问，Keychain，应用ID连续；不指导删除隔离属性绕安全检查 |
| Linux | 用发布支持的DEB/RPM或AppImage | 发行版和WebKitGTK依赖、X11/Wayland、Secret Service、无托盘回退；不保证任意发行版都能运行 |

Tauri的Windows安装及更新签名机制见来源V07/V09；可构建不等于已在真实OS测试。

## 首次打开的向导

**欢迎与隐私 → 服务端地址校验 → 安全登录/短期配对 → 设备命名 → 选择明确来源 → 来源身份和格式验证 → 媒体范围 → 本地缓存/网络/后台策略 → 合成或小样本试传 → 完整性报告。**

证书异常应停止连接，不提供“永久忽略”。配对码不进日志、命令行或分享截图。选择目录前显示采集范围和媒体类型；不能把整个home目录默认为来源。未知schema应保留诊断并不启动猜测扫描。

系统安全存储不可用时明确说明，不能静默将长期token和Outbox密钥存为明文。开机启动和后台运行需要用户可见的开关；关闭窗口不等于退出原生核，托盘与设置需解释真实行为。

## 安装成功的验收

首页能显示设备身份、服务端、来源状态、最后心跳、同步阶段、待传、隔离、源缺失、磁盘与版本；用户能暂停、恢复并打开脱敏诊断。先测试文字、图片、视频、语音、普通文件，再按许可与本地同意扩大范围。

重启后Outbox恢复；睡眠唤醒不沿用失效采集租约；网络断开只排队和退避，不删未ACK内容；客户端收到heartbeat ACK不把同步计数归零。客户端采集方式与微信平台格式支持见规则R02/R09，不能读取手机沙箱。

## 更新与卸载

更新必须验签、保持单实例、安全暂停并记录本地迁移，失败可恢复；自动更新不能静默开启新采集目录或外发功能。旧版不能打开不兼容的新本地状态库。

普通卸载默认保留待传及配置数据并明确位置/风险；彻底清除必须单独确认是否存在未ACK资料，撤销设备凭证，按策略处理备份。不能卸载后声称已删除服务器端全部历史。

## 常见错误

依赖缺失→使用可信安装器或管理员提供的离线依赖；服务端401→重新安全登录；权限撤销403→联系管理员而非循环刷新；存储不足→暂停新增扫描、扩容或调整已ACK保留策略；媒体缺失→核实原件，不反复网络重传；签名错误→停止更新。

支持人员只需版本、OS、错误码、request/job ID和脱敏诊断；不索要整套微信库、Keychain、Cookie或完整token。
