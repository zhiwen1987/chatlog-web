# 日志、诊断与常见故障

记录request_id、operation_id、source、job/attempt、batch/item与必要版本；只记录最小对象定位/摘要。日志不能包含完整聊天、文件内容、绝对用户路径、OAuth token、license JWS、激活secret或私钥。开发命令日志与业务审计分开。

## 排错顺序表

| 现象 | 按顺序检查 | 禁止的“修复” |
|---|---|---|
| 全部设备突然离线 | 监控观察链/PG→server health→最后新鲜心跳→网络 | 立刻认为所有微信退出或复制心跳刷新lastSeen |
| 设备在线但没有新消息 | 来源权限/schema→采集lease→Outbox→backpressure→真实进度 | heartbeat ACK强行推进sync cursor |
| 上传反复失败 | request/part ID→实际bytes/hash→session TTL→凭证/配额/对象返回 | 跳hash校验、每次重新上传整个TB库 |
| 视频已上传不能播放 | 原件verified→安全状态/MIME→编码→转码job→前端播放器 | 覆盖原件、把失败显示成功 |
| 查不到消息 | 同一来源/日期/时区→ACL→publish/index水位→精确/近似模式→补差 | silently缩短范围或返回空列表冒充完整 |
| 功能已买仍不可用 | signed revision→grant期限→desired→依赖→ACL→提供商/外发→配额 | 改数据库entitled=true或重置用量 |
| 批量授权一半失败 | 冻结计划→逐item revision→审批窗→签名结果→fencing→发布/应用 | 重跑已成功项再加天、回退revision |
| 取消任务还显示运行 | cancel意图→安全checkpoint/子进程→已提交副作用 | 声称全部回滚或盲目杀事务 |
| 日志占满磁盘 | 原包频率→payload脱敏→轮转/限额→聚合 | 删除必要审计或未ACK记录 |

## 标准诊断包内容

产品/OS/协议版本、去敏配置摘要、错误码和时间窗、request/job ID、最近状态转换、资源统计、schema fingerprint与覆盖报告。默认不包含正文、源库、原件或密钥；需额外材料时明确目的、授权、保留及安全传递路径。

日志采集应限大小/限时间，可取消，用户能看收集范围。生产日志不直接粘贴进模型；先本地去敏并由授权人核查。样例中的恶意提示词只作为文本，不能执行。

工单至少包含复现步骤、预期/实际、影响范围、证据路径、版本、已做/未做动作、下一步和owner。没有复現时写无法复现及限制，不以删数据或扩大权限验证。
