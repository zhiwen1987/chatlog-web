# 长链任务接续与上下文预算

规则及精确流程在手册M03～M11；本页是每次中断前后的操作卡。

## 每轮开始

读取AGENTS版本、当前WORK_ITEM、允许路径、目标合同、关键完整函数和对应反例。技能只加载当前1～2个，不塞进全部历史文档、聊天记录或完整日志。provider/model和实际上下文能力按本机核验，不擅换Pro或更贵模型。

## 每轮结束/接近上下文预算

记录事实：工作区快照、dirty归属、改动摘要、合同/迁移状态、已运行命令和退出码、日志路径、运行中的进程/job、已有幂等副作用、阻塞原因、最小下一步。不要写模型内部思考、token或私人聊天。

## 恢复时

核对仓库和记录digest→检查旧子代理/命令是否仍活跃→确认owner和派工代次→读取未完成外部job/发证结果→决定恢复/取消/新工作项。不能重新执行已经付款/发证/迁移的动作，只因为旧对话不在上下文。

## 进度展示

显示父阶段/工作项、三个槽实际状态、已验收/待验收/阻塞数量、最近进度和日志入口。活跃长命令在运行环境允许时30～60秒输出事实心跳；未知总量不用百分比。没有异步任务句柄时不能说“后台继续”。

文档里规定持续推进，是在现有权限、预算和会话能力内工作，不是无限时运行承诺。工具/模型中断时留下恢复入口，不能让脚本不停花钱或擅自扩大权限。
