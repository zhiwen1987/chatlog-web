# 来源、版本与核验边界

## 本次输入

以用户本轮提供的v4.2三文件为产品规范基础：AGENTS.md、开发规则.md、开发手册.md。字节数和SHA256在[输入摘要](输入摘要.json)。旧v1～v4.1不作为第二套指令；继承业务规则并在v4.3增加文档交付门禁，不静默修改wire/数据库/许可证版本。

本轮通过GitHub连接器只读获取`zhiwen1987/chatlog-web`的README.md。它描述旧Web档案阅读器与HTTP/用户准备的明文SQLite来源，README列出npm和测试入口。本轮未克隆/修改整个仓库，未运行其build、数据库或业务测试；未确认用户DSH工作区是否已经有后续实现。

## 三种事实不混用

1. **文档设计事实**：作者、版权、范围、三代理上限、项目规则由用户要求和v4.2输入确定。
